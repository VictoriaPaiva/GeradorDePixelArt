# Documentação do projeto

- `BACKLOG.md` — atividades atuais/futuras, status e planos.
- `Template do projeto Pixel Art.docx` — documento central de contexto e continuidade.

## Regra de manutenção
Após cada evolução relevante:
1. atualizar o backlog;
2. atualizar o estado atual e próximos passos no template;
3. registrar decisões importantes;
4. atualizar histórico e ponto de retomada.
